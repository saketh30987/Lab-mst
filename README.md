# Role-Based Login + Post Management (React + Vite)

## Run
    npm install
    npm run dev

Open http://localhost:5173

## Features
- Login as Admin / Viewer (username required)
- Admin: create, edit, delete posts (Delete Post button)
- Viewer: read-only access, can search and view posts
- Search posts, post counter, success messages
- Posts persist in localStorage
- Logout returns to login form
